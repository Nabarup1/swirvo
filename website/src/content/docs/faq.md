## Is Swirvo free?

Yes: free to use at home and at work, on as many of your own devices as you like, with no ads, no account and no trial. The terms are in the [app licence](/terms).

## Can I use it for work?

Yes. Converting and editing your own business files with the official app is fine. What the licence doesn't allow is selling the app, or publishing it under your own name.

## Does anything get uploaded?

No. Everything runs on your PC; the app has no network code. See [Privacy and security](/docs/privacy-security).

## Will it overwrite or change my files?

No. Results are always new files, with a fresh name when one is taken. Dropping on the wheel copies, never moves. See [Where files go](/docs/output).

## How is it so small?

It has its own engines (PDF to Word, the Word, Excel and PowerPoint layouts, the interface) written in Rust, and uses what Windows already has (text recognition, image codecs, the media engine, archive support) instead of bundling an office suite or a video toolkit.

## Do I need Microsoft Office?

No. Swirvo converts Word, Excel and PowerPoint to PDF with its own layout engines. If Office or LibreOffice is installed, it can use them for an exact Office print and for old formats like DOC.

## Does it work on a Mac?

No. Swirvo is a Windows app, with a command-line tool for Linux.

## Is there a Linux desktop app?

Not yet. On Linux there's the `swirvo` command line for x64 and ARM64; see [Linux](/docs/linux).

## Is it open source?

The source code is public on [GitHub](https://github.com/Nabarup1/swirvo) under the **PolyForm Noncommercial License 1.0.0**: you may read, build, change and share it for any noncommercial purpose. Commercial use of the code needs a separate licence. The official app itself is free for everyone, including at work. See the [source licence](/license).

## Can I contribute?

Yes: bug reports, ideas and pull requests are welcome. See [CONTRIBUTING.md](https://github.com/Nabarup1/swirvo/blob/main/CONTRIBUTING.md).

## Can AI assistants use it?

Yes. `swirvo mcp` is a local MCP server for Claude, Cursor, VS Code and others. See [AI assistants](/docs/ai-assistants).
