## Next to the original

Results are saved **in the same folder as the original**, unless you choose another folder in [Settings](/docs/settings) or in the Board's **Save to**.

If Swirvo can't write there (a read-only folder, a protected system folder, a cloud file that isn't on this PC), it saves to **`Downloads\Swirvo`** instead and tells you.

## Names

- **Conversions** keep the name and change the extension: `Holiday.heic` → `Holiday.jpg`.
- **Tools** say what they did, in brackets: `a (merged).pdf`, `Report (pages 1-3, 7).pdf`, `clip (25 MB).mp4`. Tools that make several files put them in a new folder: `Report (parts)`, `Report (images)`.
- **Never overwritten:** if a name is taken, the new file gets a number the way File Explorer does it: `Holiday (2).jpg`.

## Your originals are safe

Swirvo never changes, moves or deletes the file you started from:

- Every result is a **new file**. Results are written to a temporary name first and moved into place in one step, so a half-written file never appears and nothing existing is ever replaced.
- Dropping on the wheel always **copies**; it can't move your file.
- Each conversion runs in its **own process**, so a damaged file can only fail its own job.

Still, keep backups of files that matter: that's good advice for any software.
