Tap <kbd>Alt</kbd> while you drag one or more files.

| Action | What it does |
|---|---|
| **Show · In folder** | Opens File Explorer with the file selected. |
| **Copy path** | Copies the file's path. Rest on it for the variants: plain, quoted, with forward slashes, or as a WSL path (`/mnt/c/…`). |
| **Terminal · Here** | Opens Windows Terminal (or PowerShell) in the file's folder. |
| **To ZIP** | Puts all the dragged files into one ZIP next to them. |
| **Board · Open** | Opens the dragged files in the [Board](/docs/board). |
| **Copy text** | Copies the text of a text file, document, slide deck or sheet to the clipboard. For a photo or screenshot, the text is read with OCR. |

> **Tip:** **Copy text** on a screenshot is the fastest way to grab an error message, a code from a photo, or an address from an image someone sent you.
