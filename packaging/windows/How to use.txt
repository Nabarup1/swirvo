SWIRVO

Start: double-click Swirvo.exe. The Swirvo icon appears in the notification area
(bottom right of the taskbar; it may be hidden under the ^ arrow).

Install (recommended, once): the first start asks "Install Swirvo?". Say Yes, or
  later right-click the Swirvo icon > Install Swirvo... It copies Swirvo to your user
  folder (no administrator rights), adds it to the Start menu (type "Swirvo" in Start
  search) and starts it with Windows. Uninstall from Windows Settings > Apps, or from
  Swirvo's Settings > General.

Settings: right-click the Swirvo icon > Settings..., or the gear in the Board.
  Theme, where new files go, default quality, starting with Windows, pausing the wheel,
  which installed programs (Office, LibreOffice, FFmpeg) Swirvo may use, and more.

Use:
  1. Start dragging a file, for example a PDF or a photo in File Explorer.
  2. Keep holding the mouse button and tap a key:
       Shift = Convert   PDF -> DOCX/TXT/EPUB, DOCX -> PDF, PNG -> JPG/WebP/PDF,
                         HEIC/RAW -> JPG, PSD -> PNG, SVG -> PNG, MP3 -> WAV,
                         XML <-> JSON, TTF <-> WOFF2, 7Z/RAR -> ZIP ...
       Ctrl  = Tools     Resize, Rotate, Compress, Strip info, Merge/Split PDFs,
                         PDF pages to images, Pages..., Extract, Checksum ...
       Alt   = Actions   Show in folder, Copy path, Terminal, Board, To ZIP,
                         Copy text (also reads text in photos)
  3. Drop the file on a wedge of the wheel.
  The new file is saved next to the original. Originals are never changed.

  Several files at once: select them, drag them all, tap the key.
  Rest on a format for a moment to choose Best / Balanced / Smallest.
  Drop on the middle of the wheel, or press Esc, to cancel.

Board (many files at once): right-click the Swirvo icon > Open Board, or drop files
  on "Board" in the Alt wheel. Drop files in, pick a target per type, Convert.

PDF pages: Pages JPG/PNG, Split, Rotate and Pages... on a PDF with several pages
  open a page picker. Click pages or type 1-3, 7, 10- , then Export.

Built into Windows and used automatically (nothing to install):
  OCR          scanned PDFs and photos of text -> TXT/DOCX, Copy text
  Image codecs HEIC, AVIF, camera RAW (with the free Store extensions)
  tar.exe      7Z, RAR, ISO, CAB -> extract or ZIP

More formats are switched on automatically when these are installed:
  FFmpeg       video (MP4, MOV, MKV, WebM, GIF...) and all audio formats
  LibreOffice  Word/PowerPoint/Excel <-> PDF using LibreOffice's own layout

Pause: right-click the Swirvo icon > Pause the wheel, when another app needs
  Shift/Ctrl/Alt while dragging. Click it again to turn the wheel back on.

Quit: right-click the Swirvo icon in the tray > Quit Swirvo.

Command line (optional):
  swirvo-cli.exe convert report.pdf --to docx
  swirvo-cli.exe tools photo.jpg
  swirvo-cli.exe tool pdf-merge a.pdf b.pdf
  swirvo-cli.exe formats --supported
