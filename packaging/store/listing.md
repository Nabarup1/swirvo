## Product name

## Short description

Drag. Tap. Convert. A fast, private file converter and PDF toolkit that runs entirely on your PC.

## Description

Swirvo converts and edits files the fastest way possible: start dragging any file, tap Shift, and drop it on a format. The converted copy appears next to the original, usually before you've let go of the mouse. No dialog, no app to open, no upload.

Behind the wheel is a full workspace, the Board. Drop in a whole folder, give every file its own target format and convert them all at once, in parallel. Search any format or tool by typing.

WORKS WITH ABOUT 96 FORMATS
• Images: PNG, JPG, WebP, TIFF, BMP, GIF, ICO; opens HEIC, AVIF, PSD, SVG and camera RAW
• Documents: PDF, Word (DOCX), ODT, RTF, EPUB, Markdown, HTML, TXT
• PDF to Word rebuilds the layout: fonts, columns, tables and pictures
• Word, Excel and PowerPoint to PDF, without Office installed
• Spreadsheets and data: Excel (XLSX), CSV, JSON, YAML, XML; PDF tables to Excel
• Audio and video through Windows' own media engine; video compression to a target size
• Fonts, subtitles and archives (ZIP, TAR, 7Z, RAR)

59 TOOLS, 35 OF THEM FOR PDF
Merge, split into your own page ranges, compress, page numbers, header and footer, Bates numbering, watermark, password protect and unlock, crop, trim, N-up, booklet, OCR to make scans searchable, redaction that removes the text rather than covering it, form filling, compare, digital signatures and PDF/A. Watermark, crop and redaction show a live preview before you save.

PRIVATE AND SAFE
• Everything runs on your PC. No account, no upload, no ads, no tracking.
• Your originals are never changed: results are always new files.
• Each conversion runs in a separate, restricted process.

FOR AI ASSISTANTS
Swirvo includes a local MCP server, so Claude Desktop, Cursor, VS Code and other AI assistants can convert files and read documents on your PC.

## Restricted capability: runFullTrust (Submission options)

Swirvo is a desktop (Win32) file converter. It needs runFullTrust to register keyboard Raw Input for its modifier-key gesture, to host an OLE drop target that receives dragged files, to read and write files the user chose anywhere on disk, to call Windows Media Foundation, Windows OCR and the user's certificate store, and to start optional converters the user installed (Microsoft Office via COM, LibreOffice, FFmpeg) as child processes. It installs no drivers or services and downloads no code.

## Notes for certification

To try it: start dragging any file in File Explorer, tap Shift while dragging, and drop on a format. The Board opens from the tray icon (double-click). Swirvo uses keyboard Raw Input only to see Shift, Ctrl, Alt and Esc during a drag; it ignores all other keys and records nothing. It doesn't run at sign-in unless the user turns on "Start with Windows" in Settings. It makes no network connections. No account or login is needed.
